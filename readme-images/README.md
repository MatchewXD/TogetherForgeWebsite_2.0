## Tips

1. Run the site locally (`npm run dev`) and open each page.
2. Use a full-width browser window (desktop layout looks best in the README).
3. Prefer 16:9 or wide captures of the main content, not tiny phone crops.
4. Save files with the **exact names** above into this folder.
5. Commit the images so GitHub visitors can see them.

Until files are added, the README will show broken-image placeholders—that is intentional.
